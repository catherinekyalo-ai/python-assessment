# Python Text Analysis Assessment

Analyzes a news article: counts a specific word, finds the most common word,
calculates average word length, and counts paragraphs and sentences.

## Usage

1. Put the article text in `article.txt` (blank line between paragraphs).
2. Run `python3 pythonAssessment.py`.
3. Enter the word to count when prompted.

## Testing

    python3 -m pytest -q

## Maintenance

- Review the code every term; update for current Python versions and PEP 8.
- Re-run the tests after every change.
